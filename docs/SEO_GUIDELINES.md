# SEO Guidelines

## Architecture

SEO is built into the page structure — not bolted on.
Every page renders correct HTML server-side. No client-side SEO rendering.

## Title tag format

```
{Page Title} | Epso
```

Homepage exception:
```
Epso – Everyday Products for Every Home
```

Rules:
- 50–60 characters maximum.
- Unique for every page.
- Include the primary keyword near the beginning.
- Set via `SEO.astro` title prop or Sanity SEO fields.

## Meta description

- 120–160 characters.
- Unique for every page.
- Read naturally — written for humans, not keyword-stuffed.
- Call to action where appropriate.
- Set via `SEO.astro` description prop or Sanity SEO fields.

## Canonical URLs

All pages have a canonical URL set automatically via `SEO.astro`:
```astro
<link rel="canonical" href={canonicalUrl} />
```

The canonical URL is the production URL (`SITE_URL` env variable + path).

## Heading hierarchy

```
h1 — Page title (exactly one per page)
  h2 — Major sections
    h3 — Subsections
      h4 — Minor subsections
```

Never skip levels. Never use headings for styling — use Tailwind classes.

## Structured data (JSON-LD)

### All pages (via BaseLayout.astro)
- `Organization` — Epso company identity
- `WebSite` — with SearchAction for site search

### Product pages
```json
{
  "@type": "Product",
  "name": "...",
  "description": "...",
  "image": "...",
  "brand": { "@type": "Brand", "name": "Epso" },
  "offers": { "@type": "Offer", "availability": "InStock" }
}
```

> Do not add price, rating, review count, or stock count unless Epso provides real data.

### Blog posts
```json
{
  "@type": "Article",
  "headline": "...",
  "datePublished": "...",
  "publisher": { "@type": "Organization", "name": "Epso" }
}
```

### All inner pages (via Breadcrumbs.astro)
```json
{
  "@type": "BreadcrumbList",
  "itemListElement": [...]
}
```

## URL structure

```
/                           Homepage
/products/                  All products
/products/{slug}/           Individual product
/category/                  Category listing
/category/{slug}/           Category + products
/blog/                      Blog listing
/blog/{slug}/               Blog post
/about/                     About page
/contact/                   Contact page
/quality/                   Quality page
/privacy-policy/            Privacy policy
/404                        Not found
```

Rules:
- Lowercase only.
- Hyphens, not underscores.
- No trailing parameters.
- Trailing slash (Astro `build.format: 'directory'`).
- Slugs generated from content name via Sanity slug tool.

## Sitemap

Auto-generated by `@astrojs/sitemap`.
Configuration in `astro.config.mjs`:
```javascript
sitemap({
  filter: (page) => !page.includes('/studio'),
})
```

Output: `/sitemap-index.xml` and `/sitemap-0.xml`.
Submit to Google Search Console after deployment.

## robots.txt

```
User-agent: *
Allow: /
Disallow: /studio/

Sitemap: https://epso.in/sitemap-index.xml
```

## Image alt text standards

| Context | Alt text format |
|---------|----------------|
| Product image | `{Product name}` |
| Category image | `{Category name}` |
| Hero image | Descriptive sentence |
| Logo | `Epso` |
| Decorative | `aria-hidden="true"` (no alt) |

Never use:
- File names as alt text
- Generic text: "image", "photo", "product image"
- Keyword-stuffed descriptions

## Internal linking

- Every product page links to its category.
- Category pages link to parent category (if nested).
- Homepage links to all root categories.
- Footer links to all major sections.
- Related products shown on product pages.

## Pagination

Product and blog listings currently show all items (no pagination).
If lists grow beyond 50 items, implement pagination with:
- `?page=2` URL parameter
- `rel="prev"` and `rel="next"` in head
- Canonical pointing to page 1 for page 2+

## Indexing controls

- Production pages: indexed (default)
- Privacy policy: `noindex` (via `noindex={true}` prop)
- 404 page: `noindex` automatically
- Do not add `noindex` to product or category pages

## Common SEO mistakes to avoid

- Thin pages with no product content (use placeholder text until content is ready)
- Duplicate titles across pages
- Missing canonical tags
- Images without alt text
- Broken internal links
- Missing meta descriptions
- Multiple h1 elements per page
